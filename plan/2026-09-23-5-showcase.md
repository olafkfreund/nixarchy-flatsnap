## Deviations / results

- **Two CLI bugs, found while designing the apply scene (step 1).** Applying
  *from the panel* on razer could not work as specified:
  1. **The flake path was hardcoded** to `/etc/nixos` when `NIXARCHY_FLAKE` is
     unset. The panel runs inside omarchy-shell, which has no test variable, and
     `nixarchy-apply` itself falls back to `programs.nixarchy.flake`. So preflight
     evaluated a different flake than apply rebuilds, for anyone who moved theirs.
     `flake()` now reads the fallback out of `nixarchy-apply`
     (`flake="${NIXARCHY_FLAKE:-<that>}"`). For the take, the clone sets
     `programs.nixarchy.flake` to itself.
  2. **Elevation was always pkexec.** On razer, `pkexec env` needs a password
     (`AUTH_ADMIN_KEEP`), and a scripted take cannot type one. With
     `NH_ELEVATION_STRATEGY` unset and passwordless sudo (`sudo -n true`), nh's
     `passwordless` is used, since a polkit prompt would ask for nothing the user
     has not already waived. Otherwise it stays pkexec.

  `tests/cli.sh` covers both (+5 assertions, 87 in total); a mutant of each
  fails. The tests now also `unset NIXARCHY_FLAKE NH_ELEVATION_STRATEGY`: nixarchy
  exports `NIXARCHY_FLAKE` in the developer's own shell, and it silently decided
  the first run. These ship as their own PR, so nixarchy can pin them without
  waiting for the media.
- **PR #6 was merged** (by the maintainer, at 11:41) with the intent, spec and
  plan only. Implementation continues on `docs/5-showcase-media`.
- **Steps 2–4, the take: the user chose "option C, test it in real life".**
  The take could not apply into a throwaway clone. razer's running shell was
  started with `NIXARCHY_FLAKE=/etc/nixos` in its session environment, and
  that beats `programs.nixarchy.flake`, so preflight evaluated the real repo
  and refused (the safety net working). So the panel applied into razer's
  **real** `~/.config/nixos`:
  - the repo was recorded first (`main @ 6844b72`, clean, 3 stashes), moved to
    nixos_config#1990's branch with a temporary override of the plugin to
    `fix/5-cli-flake-elevation`, and `nixos-rebuild switch` gave gen 2943;
  - the take's trap un-declared and applied after every run;
  - at the end, `git restore` and a switch back to `main` (HEAD, clean state
    and all 3 stashes verified), and the system went back to gen 2942 with
    2943–2945 deleted and the boot menu refreshed.
- **What the real runs found in `docs/record.sh`,** each fixed in its own commit:
  - Hyprland's Lua config needs `hl.dsp.focus({ workspace = "N" })`;
  - nix-flatpak installs after the switch returns, so the launch waits for
    `flatpak info`;
  - a cached apply finished before the process watch looked, so apply is now
    detected by the new generation;
  - `wtype d y` types a space, which the panel's any-other-key rule rightly
    treats as a cancel, so there is one key per call;
  - ffmpeg read the script from stdin (`bash -s`), hence `-nostdin` and
    `</dev/null`;
  - the trap masked the exit code.
- **A real product finding:** a nixarchy apply's switch reloads Hyprland,
  which closes any open shell panel mid-apply, so the panel never shows its
  own "— applied —". The take reopens the panel on Declared ("installed"), and
  the gate expects `installed`. It is to be raised as a nixarchy issue; it
  affects nixarchy-pkg's panel too.
- **Media: three scene GIFs instead of one.** The whole take came to 4.1 MB.
  nixarchy's gate caps a GIF at 1 MB and says to cut scenes rather than degrade
  the encoding, so there are three scene GIFs, all passing `verify-frames.sh`:
  - `flatsnap-flatpak.gif`, 588 KB: Calculator and Flatpak found;
  - `flatsnap-snap.gif`, 624 KB: hello and confinement found;
  - `flatsnap-apply.gif`, 871 KB: installed found, with the build log cut to
    its first 3 s and last ~2 s.

  All three have no error, failed or refused text. Removal became two stills
  (10, 11): it changes a line of text at a time, and the gate's diversity check
  rightly calls that static. Weakening `--min-distinct` was not an option.
- **Privacy:** all 11 stills and all 27 gate samples were looked at. The
  captures show the bar (clock, icon badges, no text), public store data, and
  the apply log, whose nvd diff names razer's hostname and packages — not
  secret, stated in the PR. Nothing else.
- **Step 7: done as olafkfreund/nixarchy#921 (issue #920).** GIFs `features/flatsnap.gif` (the Flatpak scene) and `features/flatsnap-apply.gif`, plus stills `plugins/flatsnap-{snap,installed}.webp`, on `manual/plugins`, `manual/flatpak-and-snap`, the front page (after Packages, plus a bullet) and the README grid row 1. The spec named a `flatsnap-card` still for nixarchy too; it went unused and was not shipped. nixarchy's docs steps, `readme-counts --check` and `jekyll build` are green locally; the front page was checked in a headless screenshot.
