# Plan: show the plugin working, on its own site and on nixarchy's

## Approved decisions (self-contained)

- **Where:** everything is captured on **razer**, the standing test host. Its
  screen is 1920x1080. Record the 16:10 region **1728x1080+96+0**, which gives a
  **900x563** GIF and **1280x800** `.webp` stills (quality 85).
- **Recorder:** `gpu-screen-recorder -w region -region 1728x1080+96+0 -f 30 -cursor no`,
  stopped with SIGINT. Stills with `grim -g "96,0 1728x1080"`.
- **Session:** as in olafkfreund/nixarchy#914 step 7.
  - A `/tmp` clone of nixos_config, with nixarchy on the version that ships the
    plugin and nixos_config's own nix-snapd removed; activate it with
    `switch-to-configuration test`.
  - The plugin is installed by nixarchy and enabled by its post-boot hook.
  - Apply writes only to the clone (`NIXARCHY_FLAKE`).
- **Desktop for the take:**
  - Record the theme and background, then set Tokyo Night with Winding Road.
  - Use an empty workspace, with Do Not Disturb on.
  - Check the bar for personal data before recording, and hide widgets if
    needed (recorded here).
  - Restore everything afterwards.
- **Scenario** (`docs/record.sh`, fixed, `wtype`-driven):
  1. open → `01-empty`
  2. Flathub URL `org.gnome.Calculator` + `Enter` → `02-flatpak-card`
  3. `Enter` queues
  4. `hello` + `Ctrl+S` + `j` → `03-snap-search`
  5. `Enter` on hello-world, then `c` → `04-snap-card`
  6. `x` → `05-classic-confirm`, then `Esc`
  7. back to stable, `Enter` queues
  8. `Tab` → `06-declared`
  9. `a` → `07-apply-log`
  10. Calculator launched → `08-calculator`
  11. remove both and apply

  Scene timestamps go to `scenes.tsv`.
- **Encode:**
  1. Cut the apply to its first and last 3 s.
  2. Take 4 fps frames with `mpdecimate` and `-fps_mode vfr`.
  3. Run nixarchy's own `tests/demo/encode-gif.sh` (from `NIXARCHY_SRC`, by
     default the prefetched `github:olafkfreund/nixarchy`).

  The caption and alt text say "build log shortened".
- **Gate:** nixarchy's `tests/demo/verify-frames.sh --expect Calculator --expect
  Flatpak --expect applied --forbid 'error|failed|refused' --max-bytes 1000000`.
  A failing GIF is never committed.
- **Clean-up:** an always-run `trap`: close the panel, un-declare, apply, restore
  the theme, background and Do Not Disturb, switch back to the starting
  generation and delete the test ones, and remove `flatsnap.nix` and the
  `enabled-once` marker. Post the final generation on the bus.
- **Plugin site (this repo):**
  - `docs/index.md`: the `<pre>` mock goes, the hero is `img/flatsnap.gif`, the
    scenes get stills `02`/`04`/`07`, and a strip carries `05`/`06`; each image
    links to itself.
  - `README.md`: the GIF via its Pages URL.
- **nixarchy site (follow-up PR after #914, its own nixarchy issue):**
  - `docs/img/features/flatsnap.gif` and `docs/img/plugins/flatsnap-{card,snap}.webp`.
  - `plugins.md`: the section gets the GIF and stills.
  - `flatpak-and-snap.md`: the GIF, plus the Snap still in Security.
  - `docs/index.md`: a paragraph and the GIF after `install.gif`, and a bullet in
    "Panels, not terminals".
  - README grid row 1: Packages | Flatpak & Snap. "recorded in a VM" gets the
    honest exception.
- **Shared host:** read the bus and claim razer before the take; hold if anyone
  has its desktop.

## Steps

One commit per step on `docs/5-showcase`, except step 3, which commits media only after the gate passes.

1. **`docs/record.sh`:** the scenario, the recording, stills, the apply cut, the
   encode, the gate, and the `trap` clean-up. Idempotent setup: it refuses to
   start if the panel is open, if razer is not on the recorded generation, or if
   `flatsnap.nix` exists.
   → Verify with `shellcheck docs/record.sh`, and a dry run (`--dry-run`: prints
   the `wtype` and ffmpeg steps and touches nothing) on razer.
2. **razer session:**
   1. Read the bus, then claim razer.
   2. Record the generation, theme and background.
   3. Build the `/tmp` clone (nixarchy on #914's head, or main if merged), then
      `switch-to-configuration test`.
   4. Run the defaults hook with the session's environment, and confirm the
      plugin is enabled.
   5. Take one still of the bare region and inspect the bar (D1.4); hide
      widgets if needed and write down what was changed.

   → Verify: the plugin opens, and the bare still shows nothing personal.
3. **Record** with `docs/record.sh` (the real take).
   → Verify:
   - `verify-frames.sh` passes;
   - the GIF is under 1 MB;
   - every still and the sampled frames are looked at, with no personal data;
   - on failure, fix the script (a new commit), re-run, and record why here.
4. **Clean-up check:** razer is on the recorded generation, theme and
   background, with no `flatsnap.nix`, no demo apps, no `enabled-once` marker,
   and the plugin not installed. Post on the bus.
   → Verify: each value compared with what step 2 recorded.
5. **Plugin site:** `docs/index.md` with the GIF and stills, the mock removed;
   `README.md` with the GIF.
   → Verify: `jekyll build -s docs` passes and a local headless screenshot shows
   it. After merge, the live site does too.
6. **PR #6 ready:** results, the gate output, and the privacy statement. Merge
   with a merge commit once approved.
   → Verify: the live Pages site shows the media (a headless screenshot).
7. **nixarchy follow-up** (once #914 is merged):
   1. Open a nixarchy issue.
   2. Create a branch from main and copy the files.
   3. Edit `plugins.md`, `flatpak-and-snap.md`, `docs/index.md` and `README.md`.
   4. Run `build.yml`'s docs steps, `readme-counts.sh --check` and `jekyll build`
      locally.
   5. Open the PR, linking this spec.

   → Verify: CI is green and the images render on nixarchy's live site after
   merge.

## Rollback

- **Media:** revert the docs commit; the site falls back to the text-only page.
- **razer:** the `trap` restores it; failing that, switch to the recorded
  generation by hand and delete the test generations, run `omarchy-theme-set`
  and `omarchy-theme-bg-set` with the recorded values, and turn Do Not Disturb
  off.
- **nixarchy:** revert its follow-up PR. Nothing there is referenced by code.
