# Plan: the menu's rows, card and confirmations reach a screen reader

## Summary of the approved decisions

**Problem (intent).** `Menu.qml` sets no `Accessible.*` property. List rows
have no role or name, the selected row is shown only by colour, the card is
an unnamed column of lines, and a pending confirmation (classic, override
or classic queue, delete, apply) is marked as one only by `Color.urgent` on
the footer's message line and is never announced.

**Decisions (intent and spec review):**

- D1. The first razer step is an AT-SPI probe with the menu open. If
  quickshell exposes no tree, the properties still land, the Quickshell gap
  is listed in the PR as a follow-up (not opened), and the PR says the
  change is unverified at runtime.
- D2. Fixed here, with the `ListItem` shape of
  `olafkfreund.govee/GoveeMenu.qml:233-236` and
  `nixarchy.herdr/Card.qml:248-250`. One follow-up issue copies it to the
  sibling plugins after the razer check.
- D3. The armed state is conveyed by an announcement plus the prompt's
  existing text. No visual change.
- D4. The card's accessible name is the app and its store; its description
  is the trust summary.
- D5. Every non-empty status message is announced: polite, and assertive
  when armed.
- D6. The row under the cursor is announced on `j`/`k` only if the Orca pass
  shows Orca silent on cursor moves (conditional step 8).
- D7. One `armed` property in the model, replacing the two copies of the
  four-flag OR, with model tests.
- D8. The trust summary includes "permissions unknown", and after #27 also
  its manifest-escape line.
- D9. This merges last: #36 → #28 → #27 → #26.

**Runtime.** Qt 6.11.2 (quickshell 0.3.1) has
`Accessible.announce(text, politeness)` (Qt 6.8+). A Qt Quick `Text` is
already a `StaticText` named by its text, so no `Line` needs a property.

**Constraints.** No colour, size, layout, key or text change. The menu stays
keyboard only. `Line` stays `Text.PlainText`; names and announcements are
the same plain strings. Colours stay `Color.*`, font sizes bare
`Style.font.*`. Nothing runs on p620 except local tests; the real
`nixarchy-apply` is never run by this task, not even on razer.

Line numbers below are for main at d3a2744 and will move in step 1.

   The walker (read-only; copy to razer as `/tmp/atspi-walk`):

   ```bash
   #!/usr/bin/env bash
   # Walk the AT-SPI tree of apps whose name matches $1, to depth $2.
   set -u
   want=${1:-quickshell} max=${2:-12}
   A=$(gdbus call --session -d org.a11y.Bus -o /org/a11y/bus -m org.a11y.Bus.GetAddress | sed "s/^('//; s/',)$//")
   call() { gdbus call -a "$A" -d "$1" -o "$2" -m "$3" "${@:4}" 2>/dev/null; }
   prop() { call "$1" "$2" org.freedesktop.DBus.Properties.Get org.a11y.atspi.Accessible "$3" | sed "s/^(<//; s/>,)$//"; }
   walk() {
     local role name desc
     role=$(call "$1" "$2" org.a11y.atspi.Accessible.GetRoleName | sed "s/^('//; s/',)$//")
     name=$(prop "$1" "$2" Name); desc=$(prop "$1" "$2" Description)
     printf '%*s%s name=%s desc=%s states=%s\n' $(( $3 * 2 )) '' "$role" "$name" "$desc" \
       "$(call "$1" "$2" org.a11y.atspi.Accessible.GetState)"
     (( $3 >= max )) && return
     local kids; kids=$(call "$1" "$2" org.a11y.atspi.Accessible.GetChildren | grep -o "'/[^']*'" | tr -d "'")
     for p in $kids; do walk "$1" "$p" $(( $3 + 1 )); done
   }
   for bus in $(call org.a11y.atspi.Registry /org/a11y/atspi/accessible/root org.a11y.atspi.Accessible.GetChildren | grep -o "':[0-9.]*'" | tr -d "'"); do
     n=$(prop "$bus" /org/a11y/atspi/accessible/root Name)
     case "$n" in *"$want"*) echo "== $bus $n"; walk "$bus" /org/a11y/atspi/accessible/root 0 ;; esac
   done
   ```

   (Tried read-only on p620: it walks Spotify's tree and shows quickshell

6. **`Menu.qml`: the card** (spec §3, D4, D8). On `cardCol`:

   Accessible.role: Accessible.Grouping
   Accessible.name: (c.name || c.id || "") + ", " + (isSnap ? "Snap" : "Flatpak")
   Accessible.description: trustSummary
   readonly property string trustSummary: {
     var v = c.verified
     var s = v === true ? "publisher verified" : v === false ? "publisher not verified" : "publisher verification unknown"
     if (!isSnap && c.permissions === null) s += ", permissions unknown"

     if (isSnap && fs.classic) s += ", classic confinement, runs without a sandbox"
     return s
   }
